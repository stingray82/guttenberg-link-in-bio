# Guttenberg Link in Bio

**Version:** 1.0.0  
**Requires WordPress:** 6.4+  
**Tested with:** WordPress 6.x / Full Site Editing themes including Twenty Twenty-Five  
**License:** GPL-2.0-or-later

Guttenberg Link in Bio is a Gutenberg-first WordPress plugin for creating highly customisable bio link pages, review landing pages, social link pages, and lightweight campaign landing pages directly inside the block editor.

It is designed as a native block suite rather than a shortcode or external page builder, giving users full control over layout, sections, buttons, icons, colours, spacing, backgrounds, and responsive typography.

---

## Features

- Gutenberg-native block editing
- Full-page background support, including FSE/theme compatibility improvements
- Link page wrapper block
- Optional sections
- Unlimited buttons
- Social icon block
- SVG, icon, and image support where available
- Responsive heading and paragraph typography controls
- Responsive text alignment controls
- Button colour controls
- Button border, shadow, and radius controls
- Section spacing and padding controls
- Multiple layout/style presets
- Multiple button type presets
- Per-button style overrides
- Editor-safe links that do not navigate while editing
- Front-end links remain fully functional

## Included Blocks

### Link Page Wrapper

The main container block for the link page.

Use this block to control:

- Full-page background colour
- Page/card background colour
- Content width
- Layout preset
- Global spacing
- Typography sizes
- Responsive alignment
- Button defaults
- Overall visual style

### Link Page Section

A section block for grouping related content and links.

Use sections for groups such as:

- Review links
- Social links
- Training videos
- Services
- Contact options
- Campaign links
- Resources

Sections support spacing, headings, optional icons/images, and nested buttons.

### Link Button

A customisable button block for internal or external links.

Buttons support:

- Label text
- URL
- Style preset
- Per-button override options
- Colours
- Border
- Shadow
- Radius
- Icon/image options where configured

### Social Icons

A social link block for displaying social platforms as icons rather than plain text.

Supports common social use cases such as:

- Facebook
- Instagram
- YouTube
- TikTok
- X / Twitter
- LinkedIn
- Website links
- Email links
- Custom icon/image options where configured

## Installation

1. Download the plugin ZIP.
2. In WordPress, go to **Plugins → Add New → Upload Plugin**.
3. Upload the ZIP file.
4. Activate **Guttenberg Link in Bio**.
5. Open or create a page in Gutenberg.
6. Add the **Link Page Wrapper** block.
7. Add sections, buttons, and social icons as needed.

---

## Recommended Page Setup

For best results, create a dedicated page and use a blank or minimal template if your theme provides one.

Suggested setup:

1. Create a new page.
2. Set the page template to blank, canvas, or no-header/no-footer if available.
3. Add a **Link Page Wrapper** block.
4. Configure the full-page background colour.
5. Add headings, paragraphs, sections, buttons, and social icons.
6. Publish the page.

The plugin includes compatibility improvements for Full Site Editing themes, but theme templates may still affect spacing depending on the active theme.

---

## Editor Behaviour

Links inside the Gutenberg editor are disabled from navigating while editing. This prevents accidental page changes when clicking buttons or social links inside the editor.

On the front end, links work normally.

## Compatibility Notes

The plugin is designed for modern Gutenberg editing and has been tested with block themes and Full Site Editing workflows.

For the cleanest output, use a page template with minimal theme spacing. Some themes may apply their own wrapper margins, padding, or content width rules.
