# Guttenberg Link in Bio

A lightweight Gutenberg block suite for building fully customisable Link in Bio pages directly inside WordPress.

## Version

1.0

## Requirements

- WordPress 6.5+
- PHP 8.0+

## Blocks Included

- **Link Page Wrapper**
- **Link Page Section**
- **Link Button**
- **Social Icons**

## Features

- Gutenberg-native Link in Bio page builder
- Full-page background colour support
- Section-based layouts
- Custom buttons
- Social icons
- Font Awesome support
- SVG/PNG social icon support
- Responsive typography controls
- Responsive text alignment controls
- Layout presets
- Button style presets
- Per-button style overrides
- FSE-friendly background handling
- Editor-safe links that do not navigate while editing

## Installation

1. Upload the plugin ZIP via **Plugins → Add New → Upload Plugin**.
2. Activate **Guttenberg Link in Bio**.
3. Create or edit a page.
4. Add the **Link Page Wrapper** block.
5. Add sections, buttons and social icons inside it.

## Notes

The plugin uses Font Awesome from the CDNJS CDN for icon rendering.
